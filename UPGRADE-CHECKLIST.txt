- + Load never starts an idle queue and never interrupts an active sender.
- Start Workflow checks for pending items, confirmation, and sender-lock ownership before appending.
- A workflow is appended atomically; 100 queued prompts is still the maximum.
- Recent Activity is view-only; shortcut and disclosure do not mutate queue records.
- A missing keyboard shortcut can be resolved in Chrome's extension shortcut settings.
